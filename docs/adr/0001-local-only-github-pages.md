# Local-only progress, Backupcode, GitHub Pages

RekenTrainer has no accounts and no cloud sync: a Speler’s progress lives on the device, with optional Backupcode transfer. The app is published as a public static PWA on GitHub Pages (`https://tomashanedoes.github.io/rekentrainer/`) so it can be shared as a link without running our own app server. We rejected accounts/sync (privacy, complexity, server cost) and self-hosting as the primary distribution channel (operational burden for a static client-only app).

# RekenTrainer

A small Progressive Web App for daily arithmetic practice (addition, subtraction, times tables).

**Live:** https://tomashanedoes.github.io/rekentrainer/

Vanilla HTML/CSS/JS. No accounts, no backend, no ads — progress stays on the device.

## Install on your phone

You do not need an app store. Open the live link in your phone browser, then add it to the home screen.

### Android (Chrome)

1. Open [tomashanedoes.github.io/rekentrainer](https://tomashanedoes.github.io/rekentrainer/)
2. Tap the browser menu (⋮)
3. Choose **Install app** or **Add to Home screen**
4. Confirm — RekenTrainer appears like a normal app icon

### iPhone / iPad (Safari)

1. Open [tomashanedoes.github.io/rekentrainer](https://tomashanedoes.github.io/rekentrainer/) in **Safari** (not Chrome)
2. Tap the **Share** button
3. Tap **Add to Home Screen**
4. Tap **Add** — open it from the home screen next time

### Desktop (optional)

Chrome or Edge may show an install icon in the address bar. You can also use the browser menu → **Install RekenTrainer**.

## Using it

- Create a profile with a name (or use a backup code on another device)
- Pick **Avontuur**, **Onderwerp oefenen**, or **Snelle ronde**
- Each practice round is ten sums; difficulty adapts from how the round went

Progress is stored in the browser on that device. Clearing site data removes it — use the in-app backup code if you want a copy.

## Develop locally

Open `index.html` in a browser, or serve the folder with any static server:

```bash
npx serve .
```
